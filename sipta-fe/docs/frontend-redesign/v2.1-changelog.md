# SIPTA v2.1 — Semester Report, UI Primitives, Dark-Mode Compat, Smoke Tests

_Follow-up release layered on top of v2.0. Adds the read-only semester-history report picker, extracts shared UI primitives into `app/components/ui/*`, closes the `bg-white`-in-dark-mode fidelity gap globally, and ships a Playwright smoke-test harness._

---

## 1. Semester Report View (`/reports/students/[student_id]`)

Implements the read-only semester-history contract documented in `docs/frontend-architecture/21-semester-student-report.md`.

**What changed in the page:**
- Reads `academic_year_id` from the URL (`useSearchParams`) and canonicalizes it via `router.replace` when missing or invalid — never mutates the operational active term.
- Fetches through the new store method `useReportStore().canonicalPerformanceStudent(studentId, academicYearId)` (added; legacy `performanceStudentsByStudent` untouched).
- Adds `<SemesterSelector />` at the top of the page (also present when data is empty so users can switch away from an empty term).
- Adds an `<Alert />` archive banner when the selected term is not active (or is closed).
- Race-safe: a monotonic `requestSeqRef` ignores stale responses when the user switches terms rapidly.
- **Read-only gating** for historical terms:
  - Both `<PencilIcon>` edit buttons (skill + knowledge) are disabled + hidden with `disabled` + `hidden` attributes + explanatory `title`.
  - `handleEditClick` and `handleScoreUpdate` return early when `editingAllowed === false`.
  - "Download PDF" button is disabled with an informative `title`; `handleDownloadPDF` guards early. (The legacy PDF endpoint has no `academic_year_id` argument, so exporting from a historical term would leak active-term data.)
- Fetch-error state now surfaces an `<Alert tone="destructive">` with a retry action instead of failing silently.

**New store method:**
```ts
// src/state/ReportStore.ts
canonicalPerformanceStudent: async (student_id: string, academicYearId?: string) => Promise<any>
```
Thin passthrough to the already-existing `reportApi.canonicalPerformanceStudent` (spelled correctly, per docs). No other store methods touched.

**New components:**
- `app/components/reports/students/SemesterSelector.tsx` — accessible academic-year picker, sorts active-first, badges the active / archive / draft status of each term.

## 3. Dark-mode compat layer

Solves the "`bg-white` cards remain literal white in dark mode" limitation documented in v2.0 without touching a single legacy TSX file. Added to `app/globals.css`:

```css
.dark .bg-white           { background-color: var(--sipta-surface); }
.dark .bg-white\/80,
.dark .bg-white\/90,
.dark .bg-white\/95       { background-color: color-mix(in oklch, var(--sipta-surface) 88%, transparent); }
.dark .bg-white\/50,
.dark .bg-white\/60,
.dark .bg-white\/70       { background-color: color-mix(in oklch, var(--sipta-surface) 55%, transparent); }
.dark .bg-white\/10,
.dark .bg-white\/20,
.dark .bg-white\/30,
.dark .bg-white\/40       { background-color: color-mix(in oklch, var(--sipta-surface) 30%, transparent); }
.dark .text-black         { color: var(--sipta-foreground); }
.dark .bg-black           { background-color: var(--sipta-background); }
```

This makes every legacy `bg-white` card in `/classroom`, `/schedules`, `/reports`, `/teachers`, `/profile`, and every legacy modal automatically inherit the dark surface layer. **Effectively closes the per-page migration gap for dark-mode fidelity in a single, reversible change.**

Component-scoped explicit colors (any inline `style={{ background: ... }}`) always win, so this is safe.

## 4. Playwright smoke tests

Configured Playwright with two projects (`chromium-desktop` at 1440×900, `chromium-mobile` on Pixel 7) plus reporters. Added scripts to `package.json`:

- `npm run test:e2e` — headless run of the smoke suite.
- `npm run test:e2e:ui` — Playwright UI mode.

**Coverage (9 tests, all passing):**

| Suite | Tests |
| --- | --- |
| `tests/smoke/login.spec.ts` | Login shell renders; required-field validation; too-short username; password reveal toggle. |
| `tests/smoke/shell.spec.ts` | Header contract; theme toggle persists to localStorage across reload; 404 renders redesigned surface; 403 renders redesigned surface. |
| `tests/smoke/semester-selector.spec.ts` | Semester selector renders and URL canonicalization backfills `?academic_year_id=<uuid>` after academic-year list resolves. |

All backend calls are stubbed via `page.route()` interception — the suite is fully hermetic and safe to run in CI without a Laravel server.
